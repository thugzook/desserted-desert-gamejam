Dodge Guy — the map

Where everything lives, what every knob does. Current as of the v3 dodge (timed + lane-matched). The Godot project is dodge-guy-gamejam/.

01How a projectile is judged

The hitbox never moves — every shot reaches the player and gets judged once, in player.gd → _resolve(), in this exact order:

1 · Parried? J pressed within parry_window and the attack is parryable → deflected back at deflect_speed_multiplier×, stamina refunded.
→
2 · Dodged? Mid-dodge and direction matches the lane (table below) → shot is disabled, ghosts through at ghost_alpha.
→
3 · I-frames? Still invincible from a recent hit → ignored.
→
4 · Hit. −1 heart, iframe_time of mercy starts.

The dodge's active window = dodge_out_time + dodge_hang_time + dodge_return_time (~0.34s default). The body's hop is animation only.

02The dodge rulebook — editable: LANE_ANSWERS, top of scripts/player.gd

LaneComes fromThe answer
ABOVEoverhead, falls down your columnSidestep — A or D
LEFT / RIGHThorizontal, body heightJump — Space
HEAD_LEFT / HEAD_RIGHThorizontal, head heightDuck — S

Add a second Vector2 to any lane's list to give it two answers. Parry works on any lane if the attack is parryable.

04Recipes for manual edits

  1. One projectile type only: open scenes/main.tscn → click Spawner → Inspector → Attacks → array size 1 (keep zippy). Optionally delete chonker.tres / spiker.tres in the FileSystem dock — nothing else references them.
  2. How many at once: Spawner → max_alive (hard cap; dodged/parried shots don't count). Pace: start_interval → min_interval over ramp_seconds. Speed: zippy.tres → speed (px/sec — 300 readable, 700 scary).
  3. Change what beats what: edit LANE_ANSWERS in player.gd.
  4. Dodge feel: Player → Dodge Feel — the window (*_times, hang = forgiveness), the flinch (dodge_distance, looks only), the snap (*_trans/*_ease dropdowns).
  5. Ghost look: .tres → ghost_alpha — 0.25 faint pass-through, 0 instant vanish.
  6. Lane mix: Spawner → lanes — duplicate an entry to weight it, delete to retire it.
